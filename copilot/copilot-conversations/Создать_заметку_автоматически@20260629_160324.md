**ai**: В Obsidian, чтобы при создании новой заметки (Ctrl+N) по умолчанию использовался определенный шаблон, вам нужно настроить это в плагине "Core plugins" (Основные плагины).

Вот пошаговая инструкция:

1.  **Включите плагин "Templates" (Шаблоны):**
    *   Откройте "Settings" (Настройки) (значок шестеренки в левом нижнем углу).
    *   Перейдите в раздел "Core plugins" (Основные плагины).
    *   Убедитесь, что плагин "Templates" (Шаблоны) включен (переключатель должен быть синим).

2.  **Укажите папку для шаблонов:**
    *   В "Settings" (Настройки) перейдите в раздел "Templates" (Шаблоны) (он появится после включения плагина).
    *   В поле "Template folder location" (Расположение папки с шаблонами) укажите путь к папке, где хранятся ваши файлы шаблонов. Например, `Templates` или `00-Templates`. Если у вас нет такой папки, создайте ее.

3.  **Создайте файл шаблона:**
    *   В указанной папке для шаблонов создайте новый файл Markdown (например, `Мой шаблон.md`).
    *   В этом файле напишите содержимое, которое вы хотите видеть в каждой новой заметке. Например:
        ```markdown
        ---
        tags: [заметка, шаблон]
        creation_date: {{date}}
        ---

        # {{title}}

        ## Обзор

        ## Заметки
        ```
        Вы можете использовать переменные, такие как `{{date}}` (для текущей даты) и `{{title}}` (для названия заметки), которые будут автоматически заменены при создании заметки.

4.  **Настройте "Default template for new notes" (Шаблон по умолчанию для новых заметок):**
    *   В "Settings" (Настройки) перейдите в раздел "Files & Links" (Файлы и ссылки).
    *   Прокрутите вниз до раздела "Default location for new notes" (Расположение по умолчанию для новых заметок).
    *   Под этим разделом вы увидите опцию "Default template for new notes" (Шаблон по умолчанию для новых заметок).
    *   Нажмите на поле и выберите ваш файл шаблона (например, `Мой шаблон.md`) из списка.

Теперь, когда вы нажмете Ctrl+N (или используете команду "Create new note"), Obsidian автоматически создаст новую заметку, используя содержимое выбранного вами шаблона.
