# Pipeline работы с заметками

## Процесс создания заметки

1. **Напиши** заметку как душе угодно
2. **Отложи** — дай ей «помариноваться»
3. **Попроси нейронку** отформатировать
4. **Отрефакторь** — внеси правки по необходимости
5. **Готово!** Закрой и отправь в хранилище или оставь на рабочем столе

## Работа с наследием

| Тег              | Назначение                                               |
| ---------------- | -------------------------------------------------------- |
| `#need_formating` | Нужно форматирование (много эмодзи, пунктов, перегружено) |
| `#need_people`   | Нужна доработка человеком                                |
| `#need_update`   | Нужно дополнение заметки                                 |
| `#completed`     | Заметка готова, завершена                                |
| `#need_tags`     | Нужно добавить теги                                      |
