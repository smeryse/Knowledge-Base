# 📅 Недели 1–2: Фундамент (критично)

## Цель

Убрать те пробелы, которые тебя сейчас «роняют».

## Темы

- list / tuple / set / dict (глубоко)
- mutable vs immutable
- `is` vs `==`
- копирование (`copy`, `deepcopy`)
- функции: аргументы по умолчанию, области видимости

## Ресурсы

- Stepik (оба курса)
- Corey Schafer (точечно)

## Практика (ежедневно)

Codewars: 8 → 7 kyu

## Контроль

Ты должен уметь ответить:
- почему `[[0]*3]*3` ломается
- почему mutable default — ошибка
- разница `is` / `==`

Если не можешь → не идёшь дальше.

# ❗ Ключевые правила

1. **Каждый день код** — без этого всё бесполезно
2. **Объясняй вслух** — ты провалился не из-за знаний, а из-за объяснения
3. **Не гони вперёд** — лучше понять 1 тему, чем «пройти» 5
