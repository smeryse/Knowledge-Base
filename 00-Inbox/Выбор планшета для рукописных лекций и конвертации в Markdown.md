## Проблема

Необходимо вести рукописные лекции для преподавателей, которые требуют такого формата, но при этом нужно интегрировать эти заметки в цифровую систему (Obsidian) для последующей обработки нейросетями и суммирования. Текущее решение с ноутбуком не подходит для быстрой рукописной фиксации.

## Дилемма выбора устройства

- **Планшет с экраном:** удобство письма «как на бумаге», автономность, возможность писать без включения ноутбука. Минусы: выше цена, скользкое ощущение стекла.
- **Графический планшет без экрана:** бюджетнее, использует экран ноутбука. Минусы: менее естественно (нужно смотреть на монитор, а не под руку), требует постоянного наличия ноутбука.

## Ключевые требования

1. **Ощущение письма:** критически важно имитировать трение карандаша о бумагу. Стекло планшета слишком скользкое.
2. **Бюджет:** устройство должно быть максимально недорогим.
3. **Интеграция:** возможность конвертации рукописного текста в Markdown для работы в Obsidian.

## Решения и рекомендации

### Улучшение эргономики

Для устранения эффекта «скольжения» по стеклу необходимо использовать:

- **Матовая защитная плёнка (Paper-like):** создаёт шероховатость, имитирующую бумагу
- **Стилус со сменными наконечниками:** мягкие или резиновые насадки улучшают тактильные ощущения

### Рекомендованные модели (бюджетный сегмент)

- **Xiaomi Pad 6:** хорошее соотношение цены и качества, поддержка стилуса
- **Lenovo (серия Tab P11/P12):** альтернативные варианты от китайских производителей
- **Б/у iPad (старые модели):** если удастся найти по низкой цене, экосистема Apple удобна для распознавания почерка, но потребует покупки совместимого стилуса (возможно, стороннего аналога Apple Pencil для экономии)

## Следующие шаги

1. Определить точный бюджет
2. Выбрать модель планшета
3. Сразу заказать матовую плёнку и подходящий стилус
4. Протестировать процесс конвертации рукописного ввода в текст/Markdown
