Короче, что такое ПСП (продукционная система Поста). По сути, это формальный способ записать алгоритм по правилу «вижу шаблон — подставляю/дописываю». В современных языках её смысловыми потомками являются декларативные правила `if-then` (в rule-движках) и регулярные выражения с группами захвата и заменой.

Начну с практики, потом немного теории.

**Задача №1.** Построить ПСП, которая порождает все слова в алфавите `{0, 1, S}`, где никакие два соседних символа не одинаковы.

У нас есть три символа. Нужно задать базовые случаи и правила, которые будут достраивать слова, не нарушая условия.

ПСП работает через шаблоны с переменными. Сначала задаём слова, которые точно подходят по условию. Это **аксиомы**: `0`, `1`, `S`. Они становятся стартовой точкой.

Дальше смотрим на образцы: `x0`, `x1`, `xS`, где `x` — переменная, обозначающая любой префикс (включая пустой). Аксиома `1` подходит под `x1` (где `x` пустое), `0` — под `x0` и т.д.

Теперь суть задачи: «соседи не одинаковые». Значит, к слову, заканчивающемуся на `1`, можно приписать только `0` или `S`. К `0` — `1` или `S`. К `S` — `0` или `1`. Это и есть **продукции**:
```
x0 → x01
x0 → x0S
x1 → x10
x1 → x1S
xS → xS0
xS → xS1
```
У каждого образца два исхода, потому что оба варианта допустимы и должны попасть в итоговое множество.

Запускаем процесс: из аксиом получаем 6 новых слов (`01, 0S, 10, 1S, S0, S1`). Теперь прогоняем их через те же правила. Каждое слово снова даст два продолжения. Процесс повторяется рекурсивно, порождая всё множество допустимых строк.

**Теперь формально.** Система Поста задаётся четвёркой `П = (A, B, V, P)`:
- `A = {0, 1, S}` — основной алфавит;
- `B = ∅` — вспомогательный алфавит (в этой задаче не используется);
- `V = {x}` — алфавит переменных;
- `P` — конечное множество продукций и аксиом, записанных выше.

**Уточнения**
1. `S` — это обычный символ алфавита, а не пустое слово. Пустое слово в теории обозначается `λ`.
2. `x` — формальная переменная. При выводе алгоритм подставляет вместо неё любые слова из `A`, проверяя совпадение с образцом. Ограничение длины `≤ d` применяется только в задаче 4 при проверке выводимости конкретных слов.
3. Эта система — **порождающая**. В лабе ещё есть задача на проверку (4). Там работает обратный алгоритм: перебираются подстановки, и проверяется, выводимо ли целевое слово из заданных с помощью продукции.
