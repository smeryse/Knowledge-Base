**Управление фокусом окон**
*   `Super + j`: Фокус вниз
*   `Super + k`: Фокус вверх
*   `Super + h`: Фокус влево
*   `Super + l`: Фокус вправо

**Перемещение окон**
*   `Shift + Super + j`: Переместить вниз
*   `Shift + Super + k`: Переместить вверх
*   `Shift + Super + h`: Переместить влево
*   `Shift + Super + l`: Переместить вправо

**Изменение размера и отступов**
*   `Ctrl + Super + -`: Уменьшить отступы (gap)
*   `Ctrl + Super + +`: Увеличить отступы (gap)
*   `Shift + Ctrl + Super + i`: Уменьшить размер сверху
*   `Ctrl + Super + i`: Увеличить размер сверху
*   `Shift + Ctrl + Super + u`: Уменьшить размер снизу
*   `Ctrl + Super + u`: Увеличить размер снизу
*   `Shift + Ctrl + Super + o`: Уменьшить размер слева
*   `Ctrl + Super + y`: Увеличить размер слева
*   `Shift + Ctrl + Super + y`: Уменьшить размер справа
*   `Ctrl + Super + o`: Увеличить размер справа

**Прикрепление (Snapping)**
*   `Ctrl + Alt + c`: Центр
*   `Ctrl + Alt + d`: 1/3 слева
*   `Ctrl + Alt + g`: 1/3 справа
*   `Ctrl + Alt + e`: 2/3 слева

**Обмен окнами (Swap)**
*   `Super + Return`: Поменять с последним активным
*   `Ctrl + Super + k`: Поменять с окном сверху
*   `Ctrl + Super + h`: Поменять с окном слева
*   `Ctrl + Super + l`: Поменять с окном справа

**Режимы окон (Плавание)**
*   `Super + c`: Переключить плавание (float)
*   `Shift + Super + c`: Всегда поверх (always float)

**Контейнеры (Разделение)**
*   `Super + z`: Разделить горизонтально
*   `Super + v`: Разделить вертикально
*   `Super + g`: Переключить режим разделения
*   `Shift + Super + s`: Режим стопки (stacked)
*   `Shift + Super + t`: Режим вкладок (tabbed)
*   `Ctrl + Alt + y`: Переключить декорации вкладок

**Рабочие области и прочее**
*   `Shift + Super + w`: Переключить тайлинг на области
*   `Super + x`: Переключить рамки (borders)
*   `Super + .`: Открыть настройки
*   `Super + w`: Переключить тайлинг (глобально)
