# ЛР 10. Вариант 2. Задания 1, 2, 3

Пару слов (α, β) будем записывать как одно слово:

**αSβ**

где **S** — разделитель.

---

## Задание 1

### 1а) Пары двоичных слов (α, β), где β — обращение α

Нужно выводить слова вида:

**αSα⁻¹**

Например:

**01S10**

потому что обращение слова 01 — это 10.

Зададим систему:

**Π₁ₐ = (A, B, V, P)**

где:

- **A** = {0, 1, S}
- **B** = ∅
- **V** = {x}

**Продукции:**

- π₁: ∅ → S
- π₂: x → 0x0
- π₃: x → 1x1

**Пояснение:** начинаем с S, затем одинаковые символы добавляются слева и справа. Поэтому справа получается обратное слово.

**Пример вывода:**

S ⇒ 1S1 ⇒ 01S10

---

### 1б) Первое слово произвольное, второе получается удалением всех единиц

Нужно выводить пары:

**αSβ**

где β получается из α удалением всех 1.

Например:

**101001S000**

потому что из 101001 после удаления единиц остаётся 000.

Зададим систему:

**Π₁ᵦ = (A, B, V, P)**

где:

- **A** = {0, 1, S}
- **B** = ∅
- **V** = {x, y}

**Продукции:**

- π₁: ∅ → S
- π₂: xSy → x0Sy0
- π₃: xSy → x1Sy

**Пояснение:**

- если к первому слову добавляется 0, то во второе слово тоже добавляется 0;
- если к первому слову добавляется 1, то во второе слово ничего не добавляется.

**Пример:**

S ⇒ 1S ⇒ 10S0 ⇒ 101S0 ⇒ 1010S00

---

### 1в) Пары слов (α, β), содержащих поровну единиц

Нужно выводить пары слов, в которых количество единиц в первом и втором слове одинаковое.

Например:

**0101S1100**

В первом слове две единицы, во втором слове тоже две единицы.

Зададим систему:

**Π₁ᵥ = (A, B, V, P)**

где:

- **A** = {0, 1, S}
- **B** = ∅
- **V** = {x, y}

**Продукции:**

- π₁: ∅ → S
- π₂: xSy → x0Sy
- π₃: xSy → xSy0
- π₄: xSy → x1Sy1

**Пояснение:**

- нули можно добавлять в любое слово независимо;
- единицы добавляются сразу в оба слова, поэтому их количество остаётся одинаковым.

## Задание 2

### Система Поста для сложения неотрицательных целых чисел в четверичной системе счисления

Четверичная система использует цифры: **0, 1, 2, 3**

Зададим систему:

**Π₂ = (A, B, V, P)**

где:

- **A** = {0, 1, 2, 3, +, =}
- **B** = {r, s}
- **V** = {x, y, z, t, u, v, w, k}

Здесь:

- **r** — служебный символ младшего разряда результата;
- **s** — служебный символ переноса;
- **k** — перенос в старший разряд.

### Аксиомы младшего разряда суммы

Запись вида:

**a + b = wr**

означает: **w** — младший разряд суммы **a + b**.

| + | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **0** | 0r | 1r | 2r | 3r |
| **1** | 1r | 2r | 3r | 0r |
| **2** | 2r | 3r | 0r | 1r |
| **3** | 3r | 0r | 1r | 2r |

То есть:

- 0+0=0r, 0+1=1r, 0+2=2r, 0+3=3r
- 1+0=1r, 1+1=2r, 1+2=3r, 1+3=0r
- 2+0=2r, 2+1=3r, 2+2=0r, 2+3=1r
- 3+0=3r, 3+1=0r, 3+2=1r, 3+3=2r

### Аксиомы переноса

Запись вида:

**a + b = ks**

означает: **k** — перенос в старший разряд.

| + | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **0** | 0s | 0s | 0s | 0s |
| **1** | 0s | 0s | 0s | 1s |
| **2** | 0s | 0s | 1s | 1s |
| **3** | 0s | 1s | 1s | 1s |

То есть:

- 0+0=0s, 0+1=0s, 0+2=0s, 0+3=0s
- 1+0=0s, 1+1=0s, 1+2=0s, 1+3=1s
- 2+0=0s, 2+1=0s, 2+2=1s, 2+3=1s
- 3+0=0s, 3+1=1s, 3+2=1s, 3+3=1s

### Специальные аксиомы

- x + 0 = x
- 0 + x = x
- x + y = y + x

### Основная продукция сложения

Пусть:

- **x + y = z** — сумма старших разрядов;
- **u + v = wr** — младший разряд суммы последних цифр;
- **u + v = ks** — перенос;
- **z + k = t** — прибавление переноса к старшей части.

Тогда:

**π: (x+y=z, u+v=wr, u+v=ks, z+k=t) → (xu+yv=tw)**

Эта продукция описывает сложение справа налево.

Например, в четверичной системе:

**13₄ + 02₄ = 21₄**

потому что:

- 3+2=1r
- 3+2=1s
- 1+0=1
- 1+1=2

следовательно:

**13 + 02 = 21**

## Задание 3

### Система Поста для вычитания неотрицательных целых чисел в двоичной системе счисления

Двоичная система использует цифры: **0, 1**

Зададим систему:

**Π₃ = (A, B, V, P)**

где:

- **A** = {0, 1, -, =}
- **B** = {r, b}
- **V** = {x, y, z, t, u, v, w, k}

Здесь:

- **r** — служебный символ младшего разряда разности;
- **b** — служебный символ заёма;
- **k** — заём из старшего разряда.

### Аксиомы младшего разряда разности

Запись:

**u - v = wr**

означает: **w** — младший разряд разности **u - v**.

| - | 0 | 1 |
|---|---|---|
| **0** | 0r | 1r |
| **1** | 1r | 0r |

То есть:

- 0-0=0r
- 0-1=1r
- 1-0=1r
- 1-1=0r

### Аксиомы заёма

Запись:

**u - v = kb**

означает: **k** — заём из старшего разряда.

| - | 0 | 1 |
|---|---|---|
| **0** | 0b | 1b |
| **1** | 0b | 0b |

То есть:

- 0-0=0b
- 0-1=1b
- 1-0=0b
- 1-1=0b

### Специальные аксиомы

- x - 0 = x
- x - x = 0

Также для одноразрядных неотрицательных разностей:

- 0-0=0
- 1-0=1
- 1-1=0

### Основная продукция вычитания

Пусть:

- **x - y = z** — разность старших разрядов;
- **u - v = wr** — младший разряд разности последних цифр;
- **u - v = kb** — заём;
- **z - k = t** — вычитание заёма из старшей части.

Тогда:

**π: (x-y=z, u-v=wr, u-v=kb, z-k=t) → (xu-yv=tw)**

Эта продукция описывает вычитание справа налево.

Например:

**10₂ - 01₂ = 01₂**

потому что:

- 0-1=1r
- 0-1=1b
- 1-1=0

следовательно:

**10 - 01 = 01**

То есть:

**2₁₀ - 1₁₀ = 1₁₀**

**Ответ:** 01₂ или без ведущего нуля: **1₂**
