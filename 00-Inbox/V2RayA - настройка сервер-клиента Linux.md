## Разновидности V2Ray

- **V2RayTun** — туннельное подключение
- **V2RayNG** — мобильная версия V2RayN
- **V2RayN** — GUI-интерфейс для работы с прокси-протоколами
- **V2RayA** — клиент для всего (в основном для серверов)
- **V2RayB** — альтернативный клиент
