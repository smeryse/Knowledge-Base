# Кластеризация графов

Процесс разбиения графов на группы так, чтобы:
- Внутри группы — вершины сильно связаны
- Между группами — слабо связаны

# Спектральная кластеризация

1. Формируем

# Матрица Лапласа

$$L=D-A$$

$D$ — диагональная матрица степеней
$A$ — матрица смежности

# Собственный вектор матрицы Лапласа

$$|L-\lambda I|v = 0$$

$v$ — собственный вектор матрицы Лапласа, $\lambda$ — собственное значение матрицы Лапласа

# Собственные значения матрицы

$$det|A-\lambda I|=0$$

где $\lambda$ — собственное значение матрицы

# Фундаментальные свойства матриц

Направление, растяжение / сжатие
